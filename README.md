# gardegypt-content-writer

**المهمة:** تحديث محتوى صفحة موجودة وبيانات Rank Math.

## آلية التشغيل
- كل مهمة JSON منفصلة داخل `jobs/`؛ نموذج البيانات في `examples/job-template.json`.
- إضافة مهمة إلى `jobs/` تشغّل GitHub Actions تلقائيًا وتنتج تقرير تشغيل.
- الإضافة لا تعني موافقة: العامل يحتاج `--apply` وعلامة الموافقة المناسبة داخل المهمة.
- منشئ الصفحات ينشئ مسودات فقط، والناشر لا ينشر إلا مسودة مطابقة للـ ID والـ slug مع موافقتي المراجعة والنشر.
- مراجع المحتوى آلي وبنيوي فقط؛ يلزم فحص بشري للمعلومات والجودة.
- مستودع التحويلات يجهز CSV لـ Rank Math ولا يغيّر التحويلات الحية.

## أسرار GitHub Actions المطلوبة
`GARD_EGYPT_SITE_URL` و`GARD_EGYPT_WP_USER` و`GARD_EGYPT_WP_APP_PASSWORD`.
استخدم HTTPS وحساب ووردبريس مخصصًا بأقل صلاحيات لازمة. لا تضع أي سر في ملفات المستودع.

## التشغيل محليًا
`python3 worker.py --input jobs/task.json` للمعاينة؛ أضف `--apply` بعد المراجعة والموافقة.
